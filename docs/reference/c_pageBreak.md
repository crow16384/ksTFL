# Insert a Page Break before the matching row

Declares a page break action for the parent
[`compute_cols()`](https://example.com/reference/compute_cols.md)
condition. This action takes no arguments; it signals the renderer to
start a new page at the given row.

## Usage

``` r
c_pageBreak()
```

## Value

Quosure-style marker (internal use within
[`compute_cols()`](https://example.com/reference/compute_cols.md))
